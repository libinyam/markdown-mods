# 数学公众号排版编辑器

用 Markdown + LaTeX 写数学文章，排成「定义 / 定理 / 评注」卡片样式，一键复制到微信公众号、知乎或 X。

![预览](preview.png)

## 在线使用

打开 **https://libinyam.github.io/markdown-mods/**

1. 左边写 Markdown，右边是手机宽度的实时预览；
2. 点「复制到公众号」，到公众号后台的正文里粘贴（Ctrl+V）；
3. 发表前用「预览」发到自己手机上看一遍。

草稿会自动保存在当前浏览器里，换浏览器或清除缓存会丢失，重要文章请另存一份 `.md`。

## 本地使用

不需要安装任何东西：

1. 下载 [`index.html`](index.html)（页面右上角 Download raw file），或者 `git clone https://github.com/libinyam/markdown-mods.git`；
2. 双击 `index.html`，用 Chrome / Edge 打开即可。

需要联网，因为公式渲染（MathJax）和 Markdown 解析（marked）都从 jsDelivr CDN 加载。

## 写法

| 写法 | 效果 |
|---|---|
| `$x^2$` | 行内公式 |
| `$$ ... $$`（单独成段） | 行间公式 |
| `# *1* 单子` | 一级标题，居中，编号自动重算 |
| `## *1.1* 代数与比较函子` | 小节标题，星号包住的编号显示为蓝色 |
| `:::theorem 定理 2.2` … `:::` | 蓝色卡片 |
| `:::proposition 命题 2.3` … `:::` | 黄色卡片 |
| `:::lemma 引理 2.4` … `:::` | 青色卡片（`fact` 同色） |
| `:::corollary 推论 2.5` … `:::` | 红色卡片（「结论」也用这个） |
| `:::definition 定义 2.6` … `:::` | 绿色卡片（`axiom` 同色） |
| `:::example 例 2.7` … `:::` | 橙色卡片 |
| `:::question 问题 2.8` … `:::` | 紫色卡片 |
| `:::remark 评注 2.9` … `:::` | 灰色卡片（未登记的类型名都是灰色） |
| `:::proof 证明` … `:::` | 白底虚线框，不参与编号 |
| `:::theorem! 预备事实` … `:::` | 类型后加 `!`：不参与编号，标题原样显示 |
| `++定理 2.2++` | 交叉引用（金色虚线） |
| `[文字](https://…)` | 自动转成 `文字[1]`，文末生成「参考资料」 |

卡片的写法是：

```markdown
:::definition 定义 1.1
$T$-代数是一个二元组 $(X,x)$，其中 $x\colon TX\to X$ 满足 $x\circ\eta_X=1_X$.
:::
```

`:::` 后面先写类型（决定颜色），再写标题（显示在标签上）。其他都是标准 Markdown。完整示例见 [`example.md`](example.md)，把它的内容粘贴到编辑器里，就能看到上图的效果。

稿子里有 `#` 一级标题时，卡片编号由脚本按一级标题重算（遇到 `#` 节号加一、卡片号归零），定理、命题、引理、事实、推论、定义、公理、例子、问题、评注共用一个序列，证明不占号。正文里 `++定理 2.2++` 的数字会按卡片手写的旧编号换成新编号，所以插一条新定理，后面的编号和引用都会跟着变；卡片标题没写编号时，引用要自己对。没有 `#` 的稿子保留手写编号。

### 应用主题

工具栏第一个按钮，把没按上表写的稿子转成上面的语法，Ctrl+Z 可撤销。认两种稿子：

- **纯文本稿**（从网页、文档里复制出来，`#` 和 `**` 都丢了）：`第2章 …` 变一级标题，`2.1 …` 变二级标题，没有句末标点的短段变加粗小标题（后面紧跟行间公式的引导句除外）；`定义 2.3（…）…` 这类段落连同紧跟的行间公式变卡片（类型带 `!`，保留原编号）；`证明 …` 变证明卡片，到 `□` / `$\square$` / `证毕` 为止。以 `；` 结尾的段落连同后面一段合成列表，每条都以 `（1）`、`1）`、`①` 开头时用有序列表。正文里的 `定理 2.3`、`定义 2.4` 等自动包成 `++定理 2.3++` 引用（公式里的不动；单字的「注」「例」不认，免得把「备注 1」「比例 2」也包进去）。
- **旧格式**：`> **定理** 设 …`（定理用引用块包住、证明在块外用 `$\square$` 收尾），块内的 `>$$…$$` 会去掉行首的 `>` 变成独立公式段。

已经是 `#`、`:::` 写法的部分不会动，所以点多次也没关系。

## 复制到公众号

复制出去的内容和右边预览完全一样，样式已经写进每个元素，公式是 SVG 图形。

- **图片**：直接在公众号后台插入，编辑器不负责上传图片；正文里的图片已限制为不超过版心宽度。
- **链接**：微信会剥掉 `<a>` 标签并留下裸地址，所以粘贴前就把链接转成了脚注——正文里只有上标 `[1]`，地址统一列在文末「参考资料」下。
- **字体**：正文使用宋体。iPhone 上显示为宋体，部分安卓手机没有中文衬线字体，会显示为黑体。

## 复制到知乎

知乎会过滤所有自定义样式，所以**卡片、颜色和网格都不会保留**，只保留标题、引用块、加粗和公式。

公式会转换成知乎自带的公式格式（`zhihu.com/equation`），行间公式末尾会自动加 `\\`，让它单独成行。

## 复制到 X（X Articles）

和知乎一样只保留标题、引用块、加粗。X 会丢掉粘贴内容里的所有图片（外链 PNG、内嵌图片、SVG 都不行），只接受 Ctrl+V 粘贴的图片文件，所以公式分两种处理：

- **行内公式**转成 Unicode 文字：`$p(x\mid y)$` → p(x | y)，`$\sum_k \pi_k = 1$` → ∑ₖ πₖ = 1，`$\mathcal{V}$` → 𝒱。遇到转不了的命令（矩阵、`\binom`、`\stackrel` 等），这个公式保留原 TeX。
- **行间公式**变成「〔公式 1〕」「〔公式 2〕」……占位。粘贴正文后，在右边预览里点一下公式，它的图片就进了剪贴板，到 X 里把光标放在对应的占位处 Ctrl+V，再删掉占位文字。

公式图片是白底、固定 1200 像素宽（公式居中），这样每张图在 X 里的字号一致。

## 在 md.doocs.org 里使用主题

如果习惯用 [md.doocs.org](https://md.doocs.org)，可以把 [`wechat-math.css`](wechat-math.css) 的内容粘贴到它的「自定义 CSS」里，写法和上表完全相同。

## 修改主题

主题 CSS 有两份，改的时候两处要保持一致：

- `index.html` 里的 `<style id="theme">`，编辑器用；
- `wechat-math.css`，doocs 用。

编辑器复制时，会按 CSS 的书写顺序把规则逐条写进元素的 `style` 属性，后写的覆盖先写的，不看选择器优先级。所以用来覆盖的规则要写在后面。
