旧稿转换

「应用主题」右边那个 ? 悬停有说明，点开是一份对照示例：同一段旧稿，左边是转换前的源码与渲染，右边是转换后的源码与渲染。想先看清楚它会把稿子改成什么样，就先点这个问号。

把「旧写法」的稿子整篇改成这个编辑器用的 ::: 写法，好让卡片、编号、配色生效。

旧写法指：定理、定义等用引用块包住（> **定理** 设 …），证明写在块外用 **证明** … $\square$ 收尾。这是普通 Markdown 的常见写法，粘进来只会显示成引用块，没有卡片样式。

怎么用：整篇粘进左侧输入框 → 点「应用主题」→ 自动改写并重新渲染。

它会做什么：

  • > **定理** 正文 → :::theorem 定理 + 正文 + :::
  • 块内的 >$$…$$ 去掉行首 >，变成独立公式段
  • **证明** … $\square$ → :::proof 证明 … :::；**另证**、**别证**、**反证** 同理
  • 识别 **定理**（Chevalley） 与 **定理（Chevalley）** 两种副标题写法
  • 标题里带类型词就认，名字写在前面也行：> **Artin $L$ 猜想** → :::question Artin L 猜想——标题原样保留，不拆名字，编号接在后面
  • **例 1** 这类带编号的类型词，编号会被剥掉，交给脚本重算
  • 标题末尾的 {名字} 当成引用名：> **定理（Chevally）**{Chevally子商} → :::theorem 定理（Chevally）{#Chevally子商}（名字不显示）；正文里写 {Chevally子商} 会自动变成 ++#Chevally子商++，渲染成卡片编号「定理 2.3」. 只认标题里声明过的名字，公式里的 \frac{a}{b} 不受影响

纯文本稿（# 和 ** 都丢了的那种）只认三样：章节标题（第 2 章 … → 一级、2.1 … → 二级）、以「；」收尾的并列条目合成列表、正文里的「定理 2.3」包成 ++定理 2.3++. 卡片不猜：纯文本里的「定理 2.2 设 …」「强 Artin 猜想 设 …」「证 …」一律原样留着，要成卡片就得先有加粗标题.

它不会做什么：不改动正文的一个字、不动公式内容。已经是 ::: 的稿子再点一次不会有任何变化。

转完建议看一眼：副标题是否落在正确位置. 正文里「定理 2.2」这种「类型词 + 数字」会被自动包成 ++…++ 并重编号，但「见上文」「前述结论」这类指代它认不出，仍需人工核对.

特殊语法

卡片:::theorem 定理 … :::，kind 决定颜色
不计数、不编号:::theorem! 预备事实 … ::: —— kind 后加 !，标题原样显示，不进编号序列
自定义标题:::proof 引理的证明 … ::: —— 冒号后那串就是标题，写什么显示什么
副标题:::theorem 定理（Beck 单子性定理） —— 全角括号里的内容跟随编号，不会被当成正文
节 / 小节# 标题 / ## 标题，两侧图标自动添加，不用手写 svg
显示节号# *3* 标题 —— 写 *3* 才把节号印在标题前；这个数字同时就是这一节的节号
交叉引用++定理 2.2++、++#beck++ —— 认卡片、填当前编号、加高亮（见下）
引用名:::theorem 定理（Beck）{#beck} —— 末尾的 {#beck} 是名字，不显示，给 ++#beck++ 指路；中文名同样可以，如 {#贝克定理}. 标题也能起名：## *1.2* 陈述{#stmt}，正文写 ++#stmt++ 就填出「1.2」（标题没编号时填标题文字），点一下跳到那节
公式$…$ 行内，$$…$$ 独立成段
导出 PDF按 A4 分页、页边距 2cm 左右；版心按网页版的 677px 排，再整体缩放，所以字号约 12pt、折行和网页版一致. 公式是矢量图形（放大不糊，但选不中、复制不了），正文文字可以选中复制
导出 HTML工具栏「导出 HTML」把当前文章存成一份独立网页，样式、公式、图片都在里面，双击用浏览器打开即可；打印时会自动去掉灰底和阴影
脚注式链接[文字](url) → 正文标 文字[1]，文末「参考资料」里列一条 [1] 文字；写成 [文字](url "注释") 的，条目就换成那条注释（注释里可以用 *斜体* 与 **加粗**）；地址留空写成 [注释]() 时，正文只留编号 [n]，方括号里的字整段收到参考资料. 这几种都不印网址
行内超链接[[文字]](url) → 正文里直接可点的链接，文末也编号，列一条 链接：url
加粗**文字** —— 额外加了 0.6px 描边，中文也能看出加粗
删除线~~文字~~
外链图片![说明](https://…) 或 <img>；自动限制在版心宽度内，不会撑破
本地图片点「图片」/ 把图拖进左边 / Ctrl+V 粘贴；源码里只留 ![名字](img1)，真图存在浏览器里，复制时一起带走
卡片内元素段落、列表、代码块、公式都能放，只有一条禁令：不能出现顶格单独一行的 :::
省略标题:::theorem 后面不写标题时，抬头直接显示类型名 theorem
路标（彩蛋）:::sign 注意 … ::: —— 黄底，标题前立一块弯道路标；不编号，不占卡片序列。旧稿里写成引用块 > **注意** 正文 的，转换时自动收成这张卡
其他表格、列表、代码块、引用块都是标准 Markdown，原样支持；--- 是分隔线

两个限制：卡片标题里不能写 $…$（标题按纯文本插入，会显示成源码）；卡片里不能出现顶格单独一行的 :::（会被当成结束符）。

插图：本地图点格式行的「图片」、拖进左边、或直接 Ctrl+V，源码里只留一行 ![名字](img1)，真图存在浏览器里。复制到公众号时带的是真图（base64）；微信若是不收，就在预览里点一下那张图，它会进剪贴板，再到公众号对应位置 Ctrl+V. 复制到 X 时图片一律换成「〔图 n〕」占位（X 会丢掉粘贴内容里的所有图片），同样点图复制后粘到占位处.

交叉引用

正文里写 ++…++，渲染时去找对应的卡片，把当前编号填进去，再加一层浅黄高亮。增删卡片以后不用回头改号.

  • ++#beck++　按名字找。卡片标题末尾写 {#beck} 起个名字（名字不显示，中文也行：{#贝克定理}）。最稳，改名、改序号、前后插卡片都不影响.
  • ++定理（Beck）++、++Beck++、++定理++　按标题找。全名、只写括号里的副标题、只写类型词都认，前提是唯一.
  • ++定理 2.2++　按编号找。编号在全文唯一，对得上就认；对不上当没认出，只把旧号换成新号.

三种颜色：浅黄高亮＝认出来了；橙色虚线＝同名的卡片不止一张，写具体点；红色虚线＝写了 #名字 却没有这张卡。后两种都保持原文不动，不会乱填.

在编辑器里点高亮的引用，预览会滚到那张卡；公众号里没有这个跳转，只是高亮文字.

行内公式与中文

公式和汉字之间的缝、标点落在哪一行，渲染时会自动处理，不用自己调.

  • 汉字旁边自动留缝：公式左右紧贴汉字时补 0.18em，相当于 xeCJK 的 \xkanjiskip。自己敲了空格就不补，两种写法都对，不会叠成两倍.
  • 标点不掉行首：公式后面紧跟的逗号、句号、右括号会被咬进同一个不断行的块里，宁可整块挪到下一行，也不让标点单独顶行首.
  • 行首禁则：正文段落带 line-break: strict，中文标点不许顶行首；另有 text-wrap: pretty 少留孤字（旧浏览器忽略这两条，不影响别处）.
  • 公式不能从中间断开：MathJax 渲染出来是一整条 SVG，浏览器没法在 = 或 + 处折行（LaTeX 可以）。超过半行宽的推导式，请自己写成 $$…$$ 独占一段.
  • 正文不两端对齐：故意留成左对齐、右侧参差。两端对齐配上不可拆的长公式，正是「上一行被扯出大洞」的根源.

前两条是写进 style 属性的，粘到公众号会跟着走；公众号若丢掉某条，只是退回浏览器默认，不影响其他部分.

本地文件

  • 新建：⌘N 清空编辑框、解除与本地文件的关联（旧内容按 ⌘Z 还能回来）.
  • 打开：点工具栏「打开」或 ⌘O，选一个 .md / .txt。内容读进来渲染，工具栏会显示文件名.
  • 保存：⌘S 直接写回当前关联的文件.没关联文件时这个按钮是灰的，不会误存到别处.
  • 另存为：⌘⇧S 选个地址存成新文件，并关联到它；之后 ⌘S 写的就是这个新文件.
    文件名的左边有个橙点，表示改动还没写盘.
  • 自动保存：一旦关联了文件，停手 1.2 秒就自动写盘，闪退也不会丢. 工具栏右侧有「自动保存」勾选框，默认开着；取消勾选后只有按 ⌘S 才写盘，橙点会一直留着提醒你. 这个选择会记住，下次打开还是你上次设的. 没关联文件时仍存在浏览器草稿里，重开还在.
  • 记住上次的文件：关掉再打开 app，会自己把上次在编的那个 .md 读回来，文件名、⌘S 的写入目标都在，不用再点一次「打开」。文件被移走或改名时，会提示一句并退回草稿，此时按「另存为」就能重新落地。网页版拿不到磁盘路径，所以这条只在本地 app 里有效.
  • 写盘只覆盖正文内容，不改文件的其他部分（这个编辑器本来就只管正文）.
  • 没保存就走：新建、打开、关窗口之前，如果文件名前面有橙点（或这份稿子还没存成文件），会先问你「保存 / 不保存 / 取消」，不会悄悄丢稿. 自动保存生效的那 1.2 秒里点关闭，可能还是会问一次.

格式按钮

中间那一行是常用格式：B 加粗、I 斜体、U 下划线、S 删除线、H1 / H2 标题、> 引用、• 无序列表、</> 行内代码、{ } 代码块、$ 行内公式、$$ 行间公式、超链接 行内链接、脚注 文末引用、图片 插图.

两个链接按钮的差别：超链接写 [[文字]](url)，正文里就是可点的链接；脚注写 [文字](url)，正文标 [1]、文末「参考资料」列一条；想要的是文献出处而不是网址，就写成 [文字](url "注释")，条目直接用那条注释. 脚注的两种写法都不印网址（公众号里链接本来也点不了）. 两者的编号在同一条序列上，按在正文里出现的先后排. 点「复制到公众号」时，微信不认 ，行内超链接会退化成纯文字，编号和文末那条「链接：url」在预览里就已经排好，复制出去一并带上.

记号已经套着时再点一次就取消；没有选区就直接插入，光标停在中间，接着打字即可. 引用和列表按行处理，选中几行就加几行.

查找与定位

  • ⌘F / Ctrl+F 打开查找条，搜的是左边源码。Enter 下一个、Shift+Enter 上一个、Esc 关闭；光标有选区时会自动填进搜索框。
  • 在右边划选一段，左边会跟着选中同一段源码；划选过程中不动，松手那一刻才同步. 左边会滚到那一行，并把它摆在与右栏选中处相同的高度（齐平），一眼就能对上看的是哪句. 同一句话出现多次时，按它在全文里的第几处对位（前后文也一起比），不会一律跳到第一处；跨段落划选就选到对应的整段.
  • 双击右边预览里的文字，左边精确选中那个词；双击公式、图标这类选不中文字的地方，就选中它所在的那一段（连公式一起选中）。
  • 同步时左边会抢焦点，右边的选区高亮随之消失——这是浏览器行为，左边不聚焦就画不出选区，两者只能要一个.

字数

底栏右侧实时显示字数与字符数，打字就更新。统计的是渲染后的正文，不是左边源码，所以 #、**、::: 这些记号不算字。字数：汉字逐字算一个，西文和数字按词算一个；字符数：不含空格与换行。公式排出来是图形，不计入；表格、列表、脚注里的文字照常计入。鼠标停在这个数字上可以看明细。

卡片一览

十几张卡片共用七组颜色。下面是拿当前主题现渲染的样张，连编号都是现算的，框内可上下滚动。

编号规则

  • 节号优先用手写的那一个：标题开头写了数字（# 3 表示论、# *3* 表示论、# 3. 表示论）就拿它当节号，卡片跟着变成 3.1、3.2…… 从 0 开始编号也一样（# 0 引言 → 0.1）。没写数字才顺延：上一节 +1。
  • 每节开头卡片序号重排；所有卡片共用一条序列：定理 3.1、命题 3.2、引理 3.3…… 不是每类各自从 1 开始。
  • 三种不占号：proof、sign、kind 后加 ! 的卡片. 它们连标题都不改写。
  • 工具栏的取消编号一键给所有卡片补 !（证明、路标不动），再点一次变成应用编号，把 ! 全去掉；两个方向都能 ⌘Z 撤销，快捷键 ⌘⇧N。
  • 标题里手写的旧编号会被剥掉重算，格式固定为 节.序；没有一级标题时用 1.x 兜底。
  • 全角括号里的副标题跟着编号走，写成「定理 1.1（Beck 单子性定理）」.
  • 节号默认不显示，写 # *3* 标题 才印在标题前；卡片编号始终按节算。
  • 正文里的 ++…++ 会去找对应的卡片再填号，见下一节.

kind 写英文小写。表里的中文词只在「应用主题」转换旧稿时识别：:::定理 能跑，但会落到没有配色的灰卡。

怎么更新

这个编辑器是单文件应用，更新就是替换 index.html；仓库版和你本地的改动可能已经分叉，覆盖前先备份现在的文件。

检查的做法是去 GitHub 读仓库 main 分支最新提交的日期，和本地版本号比：仓库更晚就给你提交说明和链接，否则显示已是最新。只读，不会自动下载或覆盖。
